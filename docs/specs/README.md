# Downloaded 3GPP references

The archives in this directory are unmodified downloads from the official 3GPP
specification archive on 2026-08-02.

| File | Specification | Version | Contents |
| --- | --- | --- | --- |
| `ts_23041_rel19.zip` | TS 23.041 — Technical realization of Cell Broadcast Service (CBS) | 19.3.0 | `23041-j30.docx` |
| `ts_29168_rel19.zip` | TS 29.168 — Cell Broadcast Centre interfaces with the EPC; Stage 3 | 19.0.0 | `29168-i00.docx` |
| `23003-j30.zip` | TS 23.003 — Numbering, addressing and identification | 19.3.0 | `23003-j30.docx` |

The archived documents are the source of truth for the LTE SBcAP delivery
implementation planned behind the CBC `Publisher` interface. TS 23.003 defines
the E-UTRAN Cell Global Identifier (ECGI), eNB ID, and Cell Identity encoding
referenced by the cell-inventory subsystem's macro eNB identity model (see
[cell-inventory.md](../cell-inventory.md)).
